# 무신사 프로모션 알림 달력

무신사 파트너 공지 텍스트를 **그대로 붙여넣으면** 행사 기간과 신청 마감일을 자동으로 읽어
달력에 표시하고, 마감 시각에 맞춰 **알림이 울리는** 단일 파일 웹앱입니다.

- 설치·빌드·서버 없음. `index.html` 을 브라우저로 열면 끝
- 데이터는 브라우저 localStorage 에만 저장 (외부 전송 없음)
- 모든 시각은 한국시간(KST) 기준

## 사용법

1. `index.html` 을 더블클릭해서 브라우저로 엽니다.
2. 상단 **🔔 알림 권한** 을 눌러 브라우저 알림을 허용합니다.
3. **＋ 공지 붙여넣기** → 무신사 공지 원문을 붙여넣으면 아래 항목을 자동 인식합니다.
   - 프로모션 명 / 세일 유형 (`경량패딩 페스티벌 - 일반세일`)
   - 진행기간 (`2026-09-09 11:00 ~ 2026-09-19 11:00`)
   - 참여조건, 참여 가능 지역, 신청 경로
   - 설명 안의 **시작일 / 1차 마감일 / 2차 마감일** 등 날짜 항목
4. 인식 결과를 확인하고 **달력에 추가**. 마일스톤마다 알림이 자동 예약됩니다.

## 일정 색상 구분

공지를 붙여넣으면 항목 종류에 따라 자동으로 색이 붙습니다. 달력 아래 범례에서도 확인할 수 있습니다.

| 색 | 종류 | 달력 표시 |
|---|---|---|
| 🟩 초록 `#059669` | 행사 시작 | `▶ 행사 시작` |
| ⬛ 슬레이트 `#475569` | 행사 종료 | `■ 행사 종료` |
| 🟥 로즈 `#e11d48` | **1차 마감** | `🔔 1차 마감일` |
| 🟧 오렌지 `#ea580c` | **2차 마감** | `🔔 2차 마감일` |
| 🟪 퍼플 `#a21caf` | 3차·최종 마감 | `🔔 최종 마감일` |
| 🟦 블루 `#2563eb` | 신청 일정(시작일 등) | `📝 시작일` |
| 🟣 바이올렛 `#7c3aed` | 직접 추가한 알림 | `⏰ …` |

- **행사 기간**은 프로모션마다 다른 색의 가로 막대로 그려집니다 (7색 자동 배정).
- 프로모션이 둘 이상이면 마감 칩 앞에 프로모션 색 점(●)이 붙어 어느 행사 건인지 바로 구분됩니다.
- 색을 바꾸려면 범례나 목록에서 프로모션을 클릭 → 편집창의 **프로모션 색상** 스와치를 고르면 됩니다.
- 마일스톤 종류(신청 마감 / 신청 일정 / 행사 시작 / 행사 종료 / 기타)도 편집창에서 바꿀 수 있고, 종류를 바꾸면 색과 알림 규칙이 함께 바뀝니다.

## 알림 규칙 (우측 ‘알림 설정’에서 켜고 끔)

| 대상 | 기본 알림 |
|---|---|
| 신청 마감일 | 3일 전 09:00 · 1일 전 09:00 · 당일 09:00 · 마감 2시간 전 |
| 행사 시작·종료 | 1일 전 09:00 · 1시간 전 · 정각 |

- 시각이 적히지 않은 날짜는 `오전` → 11:00, `오후` → 17:00, 표기 없는 마감일 → 18:00 으로 잡습니다.
- 프로모션을 클릭하면 마일스톤 시각, 개별 알림 삭제, 직접 알림 추가가 가능합니다.

## 알림 팝업 켜는 법

앱 상단 **❓ 알림 켜는 법** 버튼에 현재 권한 상태와 함께 같은 내용이 들어 있습니다.

1. **🔔 알림 권한** 클릭 → 브라우저가 묻는 창에서 **허용**
2. 이미 차단했다면 주소창 왼쪽 자물쇠/⚙ → **사이트 설정 → 알림 → 허용** → 새로고침
   (크롬·엣지 `chrome://settings/content/notifications`, 사파리는 Safari > 설정 > 웹사이트 > 알림)
3. OS 알림도 확인 — 윈도우: 설정 > 시스템 > 알림에서 브라우저 켜기 + 집중 지원 끄기 /
   맥: 시스템 설정 > 알림에서 브라우저 허용 + 집중 모드 끄기
4. **탭은 열어둡니다.** 다른 탭을 보고 있어도 울리지만 브라우저를 끄면 울리지 않습니다(탭 고정 추천).
5. `file://` 로 열면 크롬 계열은 **데스크톱 팝업을 차단**합니다. 팝업까지 원하면 http 로 여세요.
   ```bash
   npx http-server .    # → http://localhost:8080
   ```
   또는 GitHub 저장소 Settings > Pages 에서 이 브랜치를 지정해 https 주소로 접속.
6. 휴대폰에서도 받으려면 **📅 ICS 내보내기** → 구글 캘린더 > 설정 > 가져오기.

**3초 뒤 테스트 알림** 버튼으로 실제 팝업이 뜨는지 바로 확인할 수 있습니다.

## 알림이 울리는 방식

- **화면 토스트 + 알림음 3회 + 탭 제목 🔔 깜빡임** — 어디서 열든 항상 동작
- **브라우저 데스크톱 알림** — 권한 허용 + http(s) 접속 시 동작 (탭이 열려 있어야 함)
- 놓친 알림은 사라지지 않고, 페이지를 다시 열면 모아서 알려줍니다
- **ICS 내보내기** — 탭을 닫아도 받고 싶을 때. 구글/애플 캘린더에 가져오면
  각 알림 시각이 `VALARM` 으로 그대로 등록되어 휴대폰에서도 울립니다.
  프로모션 편집창의 **구글 캘린더** 버튼으로 바로 등록할 수도 있습니다.

## 파싱되는 원문 형식 예시

```
프로모션 명
경량패딩 페스티벌 - 일반세일
참여조건

* 최소 5% 이상 할인

진행기간
2026-09-09 11:00 ~ 2026-09-19 11:00 (총 10일)

참여 가능 지역
South Korea (총 1개 지역)
설명
2. 세일 신청 기간
- 시작일 : 2026.09.09 (수)
- 1차 마감일 : 2026.08.24 (월) 오전
- 2차 마감일 : 2026.09.03 (목)
```

라벨이 조금 달라지거나 날짜 표기가 `2026.9.9(수) 11:00` 처럼 섞여 있어도 인식합니다.
인식이 어긋나면 저장한 뒤 편집창에서 직접 고칠 수 있습니다.

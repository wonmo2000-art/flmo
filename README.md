# 무신사 프로모션 알림 달력

무신사 파트너 공지 텍스트를 **그대로 붙여넣으면** 행사 기간과 신청 마감일을 자동으로 읽어
달력에 표시하고, 마감 시각에 맞춰 **알림이 울리는** 단일 파일 웹앱입니다.

- 설치·빌드·서버 없음. `index.html` 을 브라우저로 열면 끝
- 데이터는 브라우저 localStorage 에만 저장 (외부 전송 없음)
- 모든 시각은 한국시간(KST) 기준

## 사용법

1. `index.html` 을 더블클릭해서 브라우저로 엽니다.
2. 상단 **🔔 알림 권한** 을 눌러 브라우저 알림을 허용합니다.
3. **＋ 공지 붙여넣기** → 무신사 공지 원문을 붙여넣으면 아래 항목을 자동 인식합니다.
   - 프로모션 명 / 세일 유형 (`경량패딩 페스티벌 - 일반세일`)
   - 진행기간 (`2026-09-09 11:00 ~ 2026-09-19 11:00`)
   - 참여조건, 참여 가능 지역, 신청 경로
   - 설명 안의 **시작일 / 1차 마감일 / 2차 마감일** 등 날짜 항목
4. 인식 결과를 확인하고 **달력에 추가**. 마일스톤마다 알림이 자동 예약됩니다.

## 알림 규칙 (우측 ‘알림 설정’에서 켜고 끔)

| 대상 | 기본 알림 |
|---|---|
| 신청 마감일 | 3일 전 09:00 · 1일 전 09:00 · 당일 09:00 · 마감 2시간 전 |
| 행사 시작·종료 | 1일 전 09:00 · 1시간 전 · 정각 |

- 시각이 적히지 않은 날짜는 `오전` → 11:00, `오후` → 17:00, 표기 없는 마감일 → 18:00 으로 잡습니다.
- 프로모션을 클릭하면 마일스톤 시각, 개별 알림 삭제, 직접 알림 추가가 가능합니다.

## 알림이 울리는 방식

- **화면 토스트 + 알림음 + 탭 제목 깜빡임** — 항상 동작
- **브라우저 데스크톱 알림** — 권한 허용 시 동작 (탭이 열려 있어야 함)
- **ICS 내보내기** — 탭을 닫아도 받고 싶을 때. 구글/애플 캘린더에 가져오면
  각 알림 시각이 `VALARM` 으로 그대로 등록되어 휴대폰에서도 울립니다.
  프로모션 편집창의 **구글 캘린더** 버튼으로 바로 등록할 수도 있습니다.

## 파싱되는 원문 형식 예시

```
프로모션 명
경량패딩 페스티벌 - 일반세일
참여조건

* 최소 5% 이상 할인

진행기간
2026-09-09 11:00 ~ 2026-09-19 11:00 (총 10일)

참여 가능 지역
South Korea (총 1개 지역)
설명
2. 세일 신청 기간
- 시작일 : 2026.09.09 (수)
- 1차 마감일 : 2026.08.24 (월) 오전
- 2차 마감일 : 2026.09.03 (목)
```

라벨이 조금 달라지거나 날짜 표기가 `2026.9.9(수) 11:00` 처럼 섞여 있어도 인식합니다.
인식이 어긋나면 저장한 뒤 편집창에서 직접 고칠 수 있습니다.

# 메타 광고 연동 준비물

리포트를 조회하려면 **광고 계정 ID** 와 **액세스 토큰** 두 가지가 필요합니다.
아래 순서대로 하면 만료되지 않는 조회용 토큰이 나옵니다.

## 1. 광고 계정 ID 확인

[비즈니스 관리자](https://business.facebook.com) → 설정 → 계정 → 광고 계정

`act_` 로 시작하는 숫자입니다. 앱에는 `act_` 를 빼고 숫자만 넣어도 됩니다.

## 2. 앱 생성

[Meta for Developers](https://developers.facebook.com/apps) → 앱 만들기

- 유형: **비즈니스**
- 생성 후 앱 ID 를 확인해 둡니다.

조회 전용이면 여기서 끝입니다. **앱 검수(App Review)는 필요 없습니다.**
본인이 접근 권한을 가진 광고 계정만 다루기 때문입니다.
다른 사람의 광고 계정까지 다루려면 그때 `ads_read` 검수를 신청해야 합니다.

## 3. 시스템 사용자 생성

개인 계정 토큰은 비밀번호를 바꾸거나 세션이 끊기면 같이 죽습니다.
서버에서 계속 돌릴 거라면 **시스템 사용자** 토큰을 쓰세요.

비즈니스 설정 → 사용자 → 시스템 사용자 → 추가

- 이름: 아무거나 (예: `flmo-reporter`)
- 역할: 관리자

## 4. 시스템 사용자에 광고 계정 배정

방금 만든 시스템 사용자 선택 → **자산 추가** → 광고 계정 → 대상 계정 선택

권한은 **광고 실적 보기(View Performance)** 만 켜면 됩니다.
이 단계를 빼먹으면 토큰은 유효한데 `code 200` (권한 부족) 이 납니다. 가장 흔한 실수입니다.

## 5. 토큰 발급

시스템 사용자 → **새 토큰 생성**

| 항목 | 값 |
|---|---|
| 앱 | 2단계에서 만든 앱 |
| 토큰 만료 | **없음** |
| 권한 | `ads_read`, `ads_management` |

권한은 하려는 일에 따라 다릅니다.

| 하려는 일 | 필요 권한 |
|---|---|
| 리포트 조회만 | `ads_read` |
| 광고 만들기(`/studio`)까지 | `ads_read` + `ads_management` |

`ads_management` 는 광고를 만들고 예산을 바꿀 수 있는 권한입니다. 이 앱이
만드는 광고는 전부 일시중지 상태지만, 권한 자체는 강력하니 토큰을 신중히
다루세요.

> 발급 화면을 닫으면 토큰을 다시 볼 수 없습니다. 바로 복사하세요.

## 6. 페이지 · 픽셀 ID 확인 (광고 생성용)

리포트만 볼 거면 건너뛰어도 됩니다. **광고를 만들려면 페이스북 페이지 ID 가
반드시 필요합니다** — 메타의 모든 광고 크리에이티브는 페이지에 귀속되기 때문입니다.

| 값 | 어디서 | 필수 여부 |
|---|---|---|
| 페이스북 페이지 ID | 페이지 → 정보 → 페이지 ID | 광고 생성에 **필수** |
| 인스타그램 계정 ID | 비즈니스 설정 → 계정 → Instagram 계정 | 선택 (없으면 페이스북에만 노출) |
| 픽셀 ID | 이벤트 관리자 → 데이터 소스 | 전환 최적화를 쓸 때만 |

시스템 사용자에게 광고 계정뿐 아니라 **페이지도 자산으로 배정**해야 합니다.
4단계와 같은 방식으로 자산 추가 → 페이지 → 대상 페이지를 고르세요.

> 픽셀은 픽셀을 심을 수 있는 도메인이 있을 때만 의미가 있습니다. 무신사로만
> 보낸다면 픽셀을 심을 수 없으니 트래픽 목표를 쓰세요. 자세한 내용은
> [무신사 연동 문서](musinsa.md)를 보세요.

## 7. 앱에 입력

```bash
npm run dev
```

`http://localhost:3000/settings` 의 **메타 광고** 탭에서 계정 ID 와 토큰을 넣고 **검증하고 저장**.

저장 전에 실제 Graph API 를 한 번 호출해 확인하므로, 저장에 성공하면 조회도 됩니다.

## 토큰이 어디에 저장되나

- `.data/settings.json` 에 **AES-256-GCM 으로 암호화**되어 저장됩니다 (파일 권한 `0600`).
- 암호화 키는 `.env.local` 의 `FLMO_ENCRYPTION_KEY` 입니다.
- `.data/` 와 `.env.local` 둘 다 `.gitignore` 에 들어 있습니다.
- 토큰 원문은 브라우저로 내려가지 않습니다. UI 에는 `EAAg****oken` 형태로만 보입니다.

CI·크론처럼 UI 를 못 쓰는 환경에서는 환경변수로 직접 넣습니다. 이쪽이 우선 적용됩니다.

```bash
META_AD_ACCOUNT_ID=act_1234567890
META_ACCESS_TOKEN=EAAG...
```

## 자주 나는 에러

| 코드 | 뜻 | 해결 |
|---|---|---|
| `190` | 토큰 무효 | 토큰 재발급 |
| `190` + subcode `463` | 토큰 만료 | 만료 **없음** 으로 재발급 |
| `200` / `10` | 권한 부족 | 4단계(자산 배정) 확인, `ads_read` 체크 확인 |
| `100` | 파라미터 오류 | 계정 ID 형식 확인 (`act_` + 숫자) |
| `803` | 계정 없음 | 계정 ID 오타 |
| `4` / `17` / `613` | 호출 한도 | 잠시 후 재시도 |

## API 버전

기본값은 **v25.0** (2026-02 릴리스, 현재 최신) 입니다.
바꾸려면 `.env.local` 에서:

```bash
META_API_VERSION=v25.0
```

메타는 버전을 약 2년간 지원하고 만료시킵니다. v23.0 은 2026-06 에 만료됐습니다.

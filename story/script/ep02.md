**1화는 「누가 센가」였다. 2화는 「이름이 뭔가」다.**

| **세하** | 001 | 세하 | 이름이 있는데 **번호를 자랑스러워한다** |

> **번호도 이름도 아닌 세 번째 것이 이 화 마지막에 도착한다.**

# 연출 메모

## 2화가 하는 일

| | |
|---|---|
| **번호가 이름을 이긴 세계를 보여준다** | 아이는 자기를 사백열둘이라 하고, 세하는 001을 자랑스러워한다 |
| **같은 대사를 90년 건너 반복한다** | *"아파요" / "곧 괜찮아져"* — 1화 F6~F7과 토씨가 같다 |
| **상층이 왜 못 배우는지 보여준다** | 40은 거짓말을 안 한다. **말이 되는 걸 적었을 뿐이다** |
| **힘의 원리를 밝힌다** | 훈련이 아니라 시간이다. *"구십 년 콩 깐 손이야"* |
| **거절의 대가를 보여준다** | 카란 사람들이 절하고 갔고, 그날 밤 카란이 없어진다 |
| **귀수의 정체를 한 컷만 흘린다** | **가슴에 정화구가 있다.** 전부 열렸고 전부 비었다 |
| **세 번째 것을 도착시킨다** | 번호도 이름도 아닌 **고리 반점** |

## 카란을 본편에 붙인 이유

`inbox.md`의 미결이 ***"S#1 원고와 이 프로젝트가 같은 작품인지"*** 였다.
붙이면 다음이 전부 한 번에 풀린다.

| 풀리는 것 | 어떻게 |
|---|---|
| **귀수가 어디 나오는가** | 카란을 먹는 것이 귀수다. 색이 아니라 형체로 처음 나온다 |
| **무속 마을이 누구인가** | G에서 절하러 온 사람들이 카란 사람들이다 |
| **거절이 왜 아픈가** | 노인들은 거짓말을 안 했다. **정말로 못 막는다** |
| **2화가 어떻게 끝나는가** | 1화는 하늘에서, 2화는 땅에서 아이가 온다 |
| **이름 축의 세 번째 항** | 번호(오래) · 이름(세하) · **반점(아기)** |

> **그리고 1화 L의 굿이 여기서 값을 한다.**
> *"저거 효과 있어요?" / "없어." / "근데 왜 해요." / "무서우니까."*
> 그 사람들이 이 밤에 없어진다.

## 기계를 어디에 얹었나

**이 영화의 그림은 하나뿐이다 — 매끈한 쪽이 항상 더 많고 더 빛난다. 그리고 진다.**

| | 이번 화의 기계 |
|---|---|
| **판정** | 스캐너 아치. **사람 손이 몸에 안 닿는다** |
| **개통** | 천장의 관절 팔 여섯. 사람은 구석에서 서판만 본다 |
| **40** | 손목에서 펴지는 판, 무광 검정 왼눈, 홍채 자리의 가는 고리 |
| **회색 제복** | 한쪽 눈이 기계. **이 건물에서는 그게 보통이다** |
| **거인** | **가슴과 어깨의 정화구.** 전부 열렸고 전부 비었다 |
| **새동네 · 카란** | **금속 없음.** 천, 가죽, 뿔, 나무뿐 |

> 아이 몸에 박는 물건이 거인 몸에도 박혀 있다.
> **한 컷만 보여주고 안개로 덮는다.** 아무도 못 봤고 독자만 봤다.

## 카란 시퀀스의 규칙 다섯

1. **안개는 소리가 없다.** 짐승 소리, 바람 소리, 천 소리는 계속 나는데 **다가오는 것만 조용하다**
2. **비명이 없다.** 노인은 소리 없이 없어지고 **옷만 남는다**
3. **땅이 안 흔들린다.** 거인이 그만한 크기로 걷는데 모래가 반응하지 않는다
4. **따뜻한 색은 세 번만.** 붉은 달 · 화살통 안의 금빛 · 하늘의 불 고리. 그 사이는 전부 8500K 청백
5. **불의 고리는 달과 같은 지름이어야 한다.** 이 각운이 이 시퀀스의 끝이다

## 왜 「오래」인가

떨어져 죽은 열세 살짜리한테 **오래 살라고 붙인 이름**이다. 그 아이는 오래 못 살았다.
새 아이가 그 이름을 물려받는다.

| | |
|---|---|
| **위** | 여울이 살아 있는 아이에게 **새 이름을 지어준다** |
| **아래** | 죽은 아이의 이름을 **살아 있는 아이가 물려받는다** |
| **그리고 카란** | 이름도 번호도 없이 **몸에 표식을 갖고 온다** |

> **N102가 이 화의 마지막 대사다.** *"이건 번호가 아닌데요."*
> 이름을 방금 받은 아이가, 이름도 번호도 아닌 것을 처음 본다.

## 40을 이렇게 쓴 이유

**40은 악당이 아니다. 40은 성실하다.**

- 대장의 증언을 듣고 **반박 가능한 것만 짚는다** — 수치를 안 쟀지, 직접 봤나
- 그리고 **아는 것 중에 제일 말이 되는 걸 적는다** — 안개
- 마지막에 대장이 진짜를 말하자 **기록하지 않는다** (D73~D75)

> **17은 죽이지만 40은 계산한다.** 이 영화에서 제일 무서운 건 40이다.
> 그리고 40이 무서운 이유는 잔인해서가 아니라 **틀리지 않아서**다.
> 주어진 정보 안에서 40의 결론은 옳다. 정보가 틀렸을 뿐이다.

**그리고 이 화에서 40의 오판은 절반만 오판이다.**
안개는 DX-11을 부수지 않았다. 그런데 **안개는 같은 밤에 마을 하나를 통째로 지웠다.**
40은 틀린 이유로 옳은 것을 두려워하고 있다.

## 223을 뺀 이유

**초고에는 223이 40에게 여울을 파는 파트가 있었다.** 이번 개정에서 뺐다.

카란이 들어오면서 2화가 **하룻밤에 두 곳이 무너지는 화**가 됐고,
거기에 안에 있는 배신자까지 넣으면 축이 셋이 된다.

> **223은 3화로 옮긴다.** 그리고 거기가 더 맞는 자리다 —
> DX-12가 실패한 다음이라야 *"제가 정보를 드리겠습니다"* 가 값이 나간다.
> 팔뚝의 시술선(B에서 스치듯 보인다)만 남겨뒀다.

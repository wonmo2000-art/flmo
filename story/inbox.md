## 2026-08-12 — 1화 재구성

**문제:** 8/8에 세계관을 크게 뒤집었는데(계급 셋 / 하늘에서 떨어진다 / DX 로봇),
그게 `outline.md`에만 들어가고 **1화 원고에는 안 들어가 있었다.**
그래서 문서끼리 말이 안 맞았다. → 1화를 그 개정에 맞춰 다시 썼다.

### 합친 것

| 어디서 온 것 | 1화 어디에 들어갔나 |
|---|---|
| 계급 셋 | **L. 굿** — 위에 빛, 아래에 굿, 그 사이 평상 |
| 하늘에서 떨어진다 | **F 회상** + **M. 떨어진다** (1화 마지막) |
| 새동네 = 떨어져 산 자들 | D24 *"폐기 구역 십일"* · G28~G31 *"오백 / 예순셋 / 열한 명"* |
| DX-11 로봇 | D·E 전체. 집행자 여덟 → **DX 일곱 + 사람 하나** |
| 무속 · 가면 · 굿 | A26 · L 전체 |
| 보라색 안개(귀수) | L17 지평선의 색으로만 |
| 상층의 오판 | G49~G53 *"뭐라고 보고합니까" / "어차피 안 믿어"* |
| 단이 거절 | I. 사수 — *"가르치면 너도 백둘이 돼"* |

### 이번에 **내가(클로드가) 정한 것** — 아니면 말해줘

1. **11기에서는 능력이 나오는 게 곧 불량 판정이었다.**
   목적이 아직 정화였으니까, 능력 발현 = 정화구 고장. 그래서 센 애만 떨어뜨렸다.
   → outline의 미결 *"떨어진 아이와 기수생은 같은 사람인가"* 를 **같은 사람**으로 합친 것

2. **1화의 끝은 거절이 아니라 「떨어짐」이다.**
   단이 거절(I)은 그대로 두고, 그날 밤 아이가 떨어지면서 **분이가 일어선다.**
   → 승낙이 단이의 부탁 때문이 아니라 **밖에서 온 사건 때문**에 온다

3. **막내의 나이를 100 → 102(생일 두 달 늦음)로 바꿨다.**
   같은 기수인데 100살이면 입소 연령 12~15세 규칙과 안 맞아서

4. **집행자 대장의 용건을 빚 독촉 → 「비우세요, 물량이 늘어납니다」로 바꿨다.**
   그래야 그날 밤 떨어지는 아이가 우연이 아니게 된다

### 아직 안 정한 것 (그대로 남김)

- 떨어진 아이의 **이름** — 이름은 여울이 짓는데 여울은 벽 안에 있다
- 여울은 왜 안 늙는가 / 분이는 왜 백둘인가
- 2D인가 실사인가

## 2026-08-12 (2차) — 카란을 본편으로 붙였다

**원모가 카란 S#1 샷리스트 전문 + 레퍼런스 이미지(천막 위의 거인 셋)를 다시 던졌고,
"미래 사이보그 느낌으로 2화 다시 구성 / 듄 느낌은 유지"를 요청했다.**

### 결정 — 8/4부터 미결이던 것

> ~~*"S#1 원고와의 연결 여부"*~~ → **같은 작품이다. 2화의 밤이 카란이 먹히는 밤이다.**

붙이니까 한 번에 풀린 것들:

| 풀린 것 | 어떻게 |
|---|---|
| **귀수가 어디 나오는가** | 카란을 먹는 것이 귀수다. 1화는 색, 2화는 형체 |
| **무속 마을이 누구인가** | 2화 G에서 절하러 온 사람들이 **카란 사람들이다** |
| **거절이 왜 아픈가** | 노인들은 거짓말을 안 했다. **정말로 못 막는다** |
| **2화의 끝** | 1화는 하늘에서, 2화는 **땅에서** 아이가 온다 |
| **이름 축의 세 번째 항** | 번호(오래) · 이름(세하) · **반점(아기)** |

### 이번에 **내가(클로드가) 정한 것** — 아니면 말해줘

1. **귀수의 가슴에 정화구가 박혀 있다.** 아이들 몸에 박는 것과 같은 세라믹 포트.
   전부 열려 있고 전부 비어 있다. **한 컷만 보여주고 안개로 덮는다.**
   → outline의 *"귀수가 죽은 자들의 형상을 하고 있다면"* 제안에 답이 되고,
   사이보그 요청과 세계관이 같은 자리에서 만난다
2. **223 파트를 3화로 옮겼다.** 카란이 들어오면서 2화 축이 셋이 되어서.
   팔뚝의 시술선만 B에 남겨뒀다
3. **카란 사람들이 2화 G에서 절하러 온 그 사람들이다.** 낙타 짐에 말린 깃발로 심어놨다
4. **말이 새동네에 도착하는 것으로 2화를 끝냈다.** S#2(아기가 보는 것)는 3화로

### 팔레트 충돌 정리

S#1은 8500K 청백 + 보라 안개, S#2는 붉은 달 1800K + 무광 검정 안개로 적혀 있었다.

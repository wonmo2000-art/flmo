# 「피폭」 — 지금 어디까지 왔나

> 파일이 많아졌다. **이 문서 하나만 보면 된다.**
> 마지막 정리: 2026-08-12 (1화 재구성)

---

## 한 줄

> **2590년. 지도에 없는 마을에 백 살 넘은 노인 열한 명이 산다.
> 상층은 그 자리를 「폐기 구역 11」이라고 부른다.
> 거기에 오늘 밤에도 아이가 하나 떨어진다.**

---

# 세계 — 이거 다섯 개가 전부다

## 1. 계급 셋

| | | |
|---|---|---|
| **위 · 클래스 A** | 하늘에 가깝다 | **땅을 안 밟는다.** 제의를 올린다 |
| **아래 · 하층민** | 지상. **전부 피폭인이다** | **마흔에 죽는다.** 무속을 따른다 |
| **떨어진 것** | 상층이 버린 아이들 | 대부분 죽는다. **안 죽은 게 새동네다** |

> 위쪽은 **제의**를 올리고 아래쪽은 **굿**을 한다.
> 둘 다 종교인데, 하나는 건축이고 하나는 몸이다.

## 2. 수명이 전부를 굴린다

| | |
|---|---|
| **바깥 사람** | 40~50에 죽는다 |
| **피폭 기수생** | **100살까지 산다** |

밖에 두면 마흔에 죽고 안에 넣으면 백까지 산다. **그러니 보내는 게 사랑이다.**
수련원은 아이를 빼앗지 않는다. **부모가 데려다준다. 대기자가 있다.**

> **악당이 필요 없다. 시스템이 스스로 굴러간다.**

## 3. 10년에 한 기수 · 20기가 마지막

| | | |
|---|---|---|
| **2400년** | **1기** | 열 명. 정화 목적 |
| … | | 10년에 한 기수. 500명씩 |
| **2590년** | **20기** | **마지막 기수.** 전투 머신 |

입소 연령 **12~15세.** 한 해 늦으면 10년을 기다려야 한다.
→ 프롤로그에서 어머니가 눈산을 넘는 이유가 이거다. **올해가 아니면 안 된다.**

## 4. 목적이 20기에 걸쳐 변한다 — **이게 이야기의 엔진이다**

| 기수 | 목적 | 능력이 나오면 |
|---|---|---|
| **1~5기** | **정화.** 인간 필터 | 아직 안 나온다 |
| **6~12기** | 여전히 정화. 부작용 관찰 | **불량품이다. 버린다** ← 분이가 여기 |
| **13~19기** | **능력이 상품이 된다** | 안 버린다. 훈련시킨다 ← 단이가 여기 |
| **20기** | **전투 머신 양성소** | 처음부터 그게 목적이다 |

> **11기에서 능력이 나온 아이는 정화구가 제 일을 안 한다는 뜻이었다.**
> 그래서 웃은 아이가 불량품이 되고, 바닥이 열리고, 떨어진다.
> **상층은 190년째 자기가 뭘 버렸는지 모른다.**

## 5. 적은 사람이 아니라 로봇이다

| | | 결과 |
|---|---|---|
| **DX-11** | 흑칠 판갑, 은 관절, 창. **얼굴이 없다** | **4초** |
| **DX-12** | 더 크고 강하다. 안개에 대비했다 | 역시 접힌다 (2막) |
| **집행자** | **사람이다.** 번호를 달고 DX를 끌고 온다 | 소모품이 아니다 |

**그래서 아무리 부숴도 아무도 안 죽는다.**
그리고 죽은 사람이 없으니 증언도 없다 → **상층은 「보라색 안개 때문」이라고 오판한다.**

> **보라색 안개 = 귀수.** 1화에서는 지평선의 색으로만 나온다.

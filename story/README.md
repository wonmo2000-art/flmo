## 한 줄

> **2590년. 지도에 없는 마을에 백 살 넘은 노인 열한 명이 산다.
> 그리고 오늘도 화물차가 아이들을 싣고 흰 벽으로 들어간다.**

## 세계의 규칙 넷

| | |
|---|---|
| **1** | 바깥 사람은 **마흔에 죽고**, 피폭 기수생은 **백까지 산다** |
| **2** | 그래서 **부모가 데려다준다.** 대기자가 있다. **악당이 필요 없다** |
| **3** | **10년에 한 기수.** 1기 2400년 → **20기 2590년, 마지막** |
| **4** | 입소 연령 **12~15세.** 한 해 늦으면 10년을 기다려야 한다 |
